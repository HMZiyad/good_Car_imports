# Good Car Imports

Good Car Imports is a web application for browsing, pre-ordering, and managing imported vehicles.

## Project Structure

- `index.php` - Homepage
- `about.php` - About Us page
- `contact.php` - Contact form and details
- `inventory.php` - Available vehicles inventory
- `vehicle.php` - Single vehicle details view
- `pre-order.php` - Vehicle pre-ordering functionality
- `admin/` - Administrative dashboard for managing inventory and requests
- `api/` - Backend API endpoints (e.g., inquiry handling)
- `assets/` - CSS, JS, and image assets
- `database/` - Database schemas and initial setup scripts
- `includes/` - Reusable PHP components (headers, footers, configurations)

## Setup & Execution

This project includes a `docker-compose.yml` for easy setup using Docker.

1. Clone the repository
2. Run `docker-compose up -d`
3. Access the application via your web browser

## Technologies Used

- PHP
- HTML/CSS/JavaScript
- Docker for containerization
